# ホームラン競争 ― 体感160km/h

ブラウザで遊べるホームラン競争ゲームです。ピッチャーが100球投げてくるので、ボールがホームベースを通過する位置を、ちょうど良いタイミングでタップして打ち返します。

## 遊び方

`index.html` をブラウザで開くだけです（スマホ推奨・PCはクリックで操作）。

- ボールがストライクゾーンを通過する位置を、通過するタイミングでタップ
- タップが早いと引っ張り（レフト方向）、遅いと流し打ち（ライト方向）
- ボールの少し下を叩くと打球が上がり、上を叩くとゴロになる
- 球種：ストレート（最速163km/h）／スライダー／カーブ／シュート／フォーク／スローボール
- 全球かならずストライクゾーンを通過する
- ホームランを打つと歓声と花火が上がる
- 1球ごとに、実際の通過点（黄色の円）とタップ位置（赤い×）、タイミングのズレ（ms）が表示される
- 試合終了画面から成績をシェアできる（対応スマホは成績画像つき。X・LINE・コピーにも対応）
- 日本語・英語に対応（端末の言語で自動選択。タイトル画面の「日本語／English」で切り替え）

## タイミング補正

スマホは画面表示やタッチ検出に遅れがあるため、ジャストのつもりでも「遅い」と判定されがちです。直近のスイングのズレの中央値から端末の遅延を自動で学習し、打撃判定から差し引きます。タイトル画面で手動調整（±10ms）や自動調整のオン/オフもできます。設定はブラウザに保存されます。

## 難易度

| 難易度 | 球速 | タイミング許容 |
| --- | --- | --- |
| 体感160km/h | 実速 | ±約75ms |
| プロ | 約0.86倍 | ±約95ms |
| ルーキー | 約0.68倍 | ±約130ms |

外部ライブラリや画像・音声ファイルは使っていません。描画は Canvas、効果音・歓声・花火の音は Web Audio API で合成しています。

## Android 版

Google Play で公開中：https://play.google.com/store/apps/details?id=jp.techgym.homerun

Capacitor で Android アプリにしています（パッケージ名 `jp.techgym.homerun`）。ビルドは GitHub Actions で行い、動作確認用 APK は Release `android-latest` からダウンロードできます。Google Play 公開までの手順は [docs/ANDROID.md](docs/ANDROID.md) を参照してください。

## iOS 版

同じ Capacitor のプロジェクトで iOS アプリにしています（Bundle ID `jp.techgym.homerun`、iPhone 縦画面）。GitHub Actions が push のたびにビルドを確認し、Secrets が登録されていれば TestFlight にアップロードします。手順は [docs/IOS_BUILD.md](docs/IOS_BUILD.md) を参照してください。
