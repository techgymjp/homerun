## 日本語

```
ホームラン競争 〜体感160km/h〜
```

**簡単な説明**（80 文字以内）

```
体感160km/hの剛速球と多彩な変化球を、タイミングよくタップして打ち返せ！全100球のホームラン競争
```

**詳しい説明**

```
160km/hの剛速球、打ち返せるか。

ピッチャーが投げ込んでくる100球を、ひたすら打ち返すホームラン競争ゲーム。
ボールがホームベースを通過する「位置」を、「ちょうど良いタイミング」でタップするだけ。
芯で捉えれば打球は夜空へ。スタンドに飛び込めば、大歓声と花火があなたを包みます。

■ 多彩な球種で打者を翻弄
・最速163km/hのストレート
・スライダー、カーブ、シュート、フォーク、スローボール
・打者の手元で鋭く曲がる変化球。ただし全球かならずストライク！
・ワインドアップの「間」も毎回変わる。ときにはクイックモーションも

■ 打撃はリアルな物理計算
・タップが早ければ引っ張り、遅ければ流し打ち
・ボールの少し下を叩けば打球が上がり、上を叩けばゴロに
・打球の速さ・角度・方向から飛距離を計算。フェンスを越えればホームラン
・1球ごとに「実際の通過点」「タップ位置」「早い／遅い ○ms」を表示。打つたびに上達できる

■ 球場の臨場感
・ナイターの球場、トランペット応援と太鼓、投球の「シュー」という風切り音
・空振りすれば観客のため息、ホームランなら大歓声と花火
・打った瞬間にスマホが振動

■ 遊びやすさ
・難易度は3段階：体感160km/h（実速）／プロ／ルーキー（練習用）
・スマホの画面やタッチの遅れを自動で補正するタイミング補正
・ホームラン数・安打・打率・最長飛距離から称号を判定。「草野球の星」から「伝説のスラッガー」まで
・成績をX・LINEなどでシェア
・試合終了後、広告を見ると「延長戦」で10球追加
・オフラインでも遊べる（広告・シェアは通信が必要）

あなたは100球で何本打てるか。さあ、打席へ。
```

## Play Console「アプリのコンテンツ」の回答の目安

- **プライバシー ポリシー**: https://techgym.jp/privacy-policy/
- **広告**: 「はい、広告を含みます」（全画面・リワード・バナー）
- **アプリのアクセス権**: 「制限なし（ログイン不要）」
- **広告 ID**: 「使用する」（目的は「広告またはマーケティング」と「アナリティクス」）
- **ターゲット ユーザー**: 13 歳以上（13 歳未満を含めると広告に制限がかかる）
- **データ セーフティ**: アプリ自体は個人情報を集めないが、Google AdMob が「デバイスまたはその他の ID（広告 ID）」と「アプリの操作（広告の表示・クリック）」を広告とアナリティクスの目的で収集・共有する。通信は暗号化されている。※ AdMob の公式ガイドに従って最終確認すること
- **コンテンツのレーティング**: カテゴリは「ゲーム」。暴力・性的表現・ギャンブル・ユーザー間のやり取りはいずれも「なし」
- **カテゴリ**: ゲーム → スポーツ
